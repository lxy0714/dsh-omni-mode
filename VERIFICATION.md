# 验证入口 / Verification

[中文](#中文) · [English](#english)

## 中文

公开验证记录见[验证分层](docs/verification.md#中文)。不发布原始 Session、进程 ID 或作者机器路径。

运行 `npm ci --ignore-scripts` 和 `npm run verify` 可复现检查。集成使用真实 Harness 服务与本地确定性模拟推理，不调用付费供应商。

## English

Public notes live in [verification layers](docs/verification.md#english). Raw sessions, process IDs and author-machine paths are not published.

Run `npm ci --ignore-scripts` and `npm run verify`. Integration uses real Harness services and deterministic local mock inference, not a paid provider.
